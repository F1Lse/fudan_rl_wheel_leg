# 从平衡与上下台阶基座重训旋转

## 基座与已测能力

使用 `logs/wheel_legged/Sep13_01-18-42_flat_stability_longlegs_s05_final_mixed_consolidation/model_56500.pt`。它是平衡与混合地形课程的最终 checkpoint，训练包含平地、上下台阶和其他地形。该训练日志在第 56499 步的平均回合长度为 1888/2000 步、平均地形等级 5.22；这只能说明训练期间的总体表现，仍需专门的台阶保留评测。

2026-09-25 固定旋转基线（高度 0.16 m，先站稳 2 秒，8 秒回合）：标称动力学中，±1–4 rad/s 的 yaw MAE 为 0.07–0.20 rad/s，8 回合/格大多满足暂定稳定阈值。打开历史域随机化和推搡后，yaw MAE 仍约 0.1–0.7 rad/s，但 p90 漂移升至约 0.45–1.26 m，机身 tilt 和 roll/pitch 角速度也增加。原始数据在 `plane/evaluations/spin/Sep13_model_56500_{nominal,baseline}_seed101/`。

所以起点已具备双向低速旋转；首要缺口是抗扰稳定性及 5 rad/s 以上的速度覆盖。原台阶 PT 保留为独立部署候选，旋转在新分支训练，以免直接覆盖其地形能力。如果最终必须合为一份策略，须增加上下台阶保留评测及混合场景训练。

## 单阶段训练与晋级

脚本 `plane/scripts/train_spin_from_flat.sh` 每次只训练一个目标 yaw 阶段，不会自动升速。首个试验从 56500 分叉，目标 ±5 rad/s，300 轮，`nominal` 窄范围动力学随机化。`spin_fixed` 采样在每个训练批次中保留 10% yaw=0、55% 幅值为目标的 70%–100%、35% 精确目标，符号等概率；高度 0.16 m、vx=0。非饱和 yaw L1 奖励避免大误差时高斯奖励近乎常数；保留原基座的主要姿态、高度和空闲站稳奖励。续训重置 Adam 状态，避免沿用台阶任务的优化器动量。完整环境配置记录在训练 manifest 中。

每个 stage 在下一轮训练前执行：

1. 同一评测设置同时测**父 checkpoint 和新 checkpoint**，至少覆盖上一个可用转速及当前目标的正负方向；种子 101、102，每格至少 20 回合。用 `WLG_EVAL_TARGET=eval_targets/spin_idle_v1.json` 补静止保留测试。比较平均 yaw MAE、p90 倾角、roll/pitch 角速度和最大漂移，而不只看总奖励或完整回合率。
2. 标称环境的暂定晋级条件：正反两个目标的 yaw MAE ≤0.8 rad/s，p90 最大倾角 ≤15°，p90 漂移 ≤0.15 m；旧目标不能明显退化。阈值按实机用途校正。
3. 加入完整历史随机化和周期推搡，重点比较坠倒率、推搡后的姿态角速度及恢复时间。推搡使机身发生位移，不能用同一个 0.15 m 世界坐标漂移门槛判定抗扰成功；部署 actor 也没有世界坐标返回原点的观测。
4. 只有通过当前目标，才考虑将目标从 5 提至 6 rad/s。随后逐级提速；未通过时先查看失败轨迹中的轮动作、力矩、roll/pitch 和方向，而不是继续加轮次。达到 8 rad/s 前应单独验证执行器可行性和动作余量，再决定是否向 10/13 rad/s 扩展。

同设置的两组结果可用 `python wheel_legged_gym/scripts/compare_spin_evaluations.py <父目录> <候选目录> --gate-yaws=-5,-4,4,5` 逐格比较并给出非零退出码；脚本会先检查种子、命令列表、环境数、随机化及阈值是否相同。yaw=0 使用独立目标文件和阈值。暂定门槛只是筛选实验，不等于实机验收。

如果首次试验退化，回到同一个 56500 基座，只改变正向 yaw 样本比例，保持训练轮数、奖励和评测完全相同。通过正反向门槛后，再把候选从 `nominal` 切到 `robust`，量化推搡及较宽动力学分布的代价。即使两者都通过，也要与同预算的原始均匀采样方案比较，才能把收益归因于目标采样。
